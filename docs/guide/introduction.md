# 介绍

KoyukiStudyHub 是一个**类 GitBook 的 Markdown 文档展示站点**，专为个人知识库与项目文档设计。

## 核心特性

- **左侧章节目录**：支持分组与折叠展开，点击即可跳转。
- **右侧文章正文**：标准 Markdown 渲染，支持代码高亮、表格、提示块等。
- **Alice Future 设计系统**：采用 `alice-future/` 文件夹中的视觉规范，呈现纯净、未来、柔软的科技风格。
- **Docker 部署**：本地写 Markdown，打包为 Docker 镜像，部署到自有服务器与域名。
- **一键 Rebuild**：更新文章后，服务器执行 `deploy.sh` 即可重新构建并重启服务。

## 为谁而建

这个站点适合：

- 个人学习笔记整理
- 项目文档与 API 手册
- 团队知识库
- 任何需要「干净、专业、可长期维护」的文档站

## 设计哲学

> Pure Intelligence · Living Technology — 纯净智能，有生命的科技。

来自 `alice-future/` 的 Alice Future Design System，为整个站点提供：

- 以 Future Blue `#3BA7FF` 为主交互色
- 玻璃材质（Glass Material）与蓝色光阴影
- 圆润的圆角系统与呼吸感动效
- 深蓝宇宙暗色主题
