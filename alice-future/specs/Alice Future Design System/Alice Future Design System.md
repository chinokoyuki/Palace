# Alice Future Design System

Version: 1.0.0

Alice Future 是一套面向 AI、未来科技、智能设备、人机交互场景的视觉设计系统。

设计理念：Pure Intelligence · Living Technology — 纯净智能，有生命的科技。

## 1. Design Philosophy

关键词：Pure, Future, Alive, Elegant, Soft

设计原则：Less but Better；Technology Should Feel Warm

## 2. Color System

### 2.1 Primary Colors
- Alice Light: #F0F8FF (页面背景)
- Alice Sky: #8FD3FF (品牌主色)
- Future Blue: #3BA7FF (主要交互)
- Core Blue: #1769AA (强调状态)

### 2.2 Future Gradient
#F0F8FF → #8FD3FF → #3BA7FF

### 2.3 Dark Contrast
- Deep Space: #061A40 (主背景)
- Night Blue: #172554 (卡片背景)
- Ocean Shadow: #0F3D66 (组件层)
- Void Blue: #020617 (最高对比)

## 3. Shadow System

- Shadow XS: 0px 2px 8px rgba(23,105,170,0.08) — 按钮、标签
- Shadow SM: 0px 8px 24px rgba(23,105,170,0.12) — 卡片
- Shadow MD: 0px 16px 40px rgba(23,105,170,0.18) — 浮动窗口
- Shadow AI Glow: 0px 0px 50px rgba(59,167,255,0.35) — AI头像、智能核心、激活状态

## 4. Glass Material System

- Glass Light: background rgba(255,255,255,0.65), blur 30px, border rgba(255,255,255,0.5)
- Glass Blue: background rgba(143,211,255,0.18), blur 40px

## 5. Typography

- Font: SF Pro Display, SF Pro Text; 中文苹方/HarmonyOS Sans/思源黑体
- Hero标题: 48-64px; 页面标题: 32px; 模块标题: 24px; 正文: 16px; 辅助文字: 13px

## 6. UI Components

- Button: Primary bg #3BA7FF, radius 999px, shadow AI Glow, hover brightness+10% scale 1.02
- Card: radius 24px, bg light rgba(255,255,255,0.7), dark rgba(23,37,84,0.7)
- Navigation: 浮动、半透明、圆角

## 7. Animation

- Hover: 200ms; Transition: 300ms; Page: 500ms; AI状态: 1000-3000ms
- AI Pulse: scale 1→1.05, opacity 0.8→1, duration 2s

## 8. Icon Style

SF Symbols, Lucide, Phosphor; 线宽 1.5px

## 9. Layout

Grid: 12 columns; Spacing: 4, 8, 16, 24, 32, 48, 64, 96
